# 快捷键

NyaTerm 的快捷键分成两类理解最不容易混淆：

1. **应用级快捷键**：切换面板、开新会话、复制终端内容等，由 NyaTerm 处理
2. **Shell 级按键**：直接发送给远端或本地 shell，例如 `Ctrl+C`

复制终端里的文本要用应用级快捷键，shell 里的 `Ctrl+C` 不会变成复制。

## 约定

- 下表中的 **Ctrl / Cmd** 表示：Windows / Linux 使用 `Ctrl`，macOS 使用 `Cmd`
- 分组与 **设置 → 快捷键** 中的分类一致，便于对照查找
- 所有快捷键都可以改，见本页末尾的[自定义快捷键](#自定义快捷键)

## 终端操作

| 快捷键 | 功能 |
|--------|------|
| `Ctrl / Cmd + Shift + C` | 复制（无选区时复制可见终端文本） |
| `Ctrl / Cmd + Shift + V` 或 `Shift + Insert` | 粘贴 |
| `Ctrl / Cmd + Shift + X` | 粘贴选中的文本 |
| `Ctrl / Cmd + Shift + F` | 查找 |
| `Ctrl / Cmd + L` | 清屏 |
| `Ctrl / Cmd + Shift + A` | 全选可见终端内容 |
| `Ctrl / Cmd + Shift + G` | 管理同步输入组 |
| `Alt + R` | 显示命令建议（输入行为空时列出近期历史和置顶快捷命令） |
| `Ctrl / Cmd + Shift + R` | 开始或停止当前会话录制 |

终端本身也接受 `Ctrl / Cmd + V` 和右键菜单粘贴。

## 标签与会话

| 快捷键 | 功能 |
|--------|------|
| `Ctrl / Cmd + Shift + N` | 新建 SSH 会话（打开已保存连接页） |
| `Ctrl / Cmd + Alt + N` | 打开临时 SSH 链接对话框 |
| `Ctrl / Cmd + Shift + S` | 打开命令面板 |
| ``Ctrl / Cmd + ` `` | 新建本地终端 |
| `Ctrl / Cmd + Shift + W` | 关闭当前标签 |
| `Ctrl + Tab` | 下一个标签 |
| `Ctrl + Shift + Tab` | 上一个标签 |
| `Ctrl / Cmd + 1-8` | 跳转到第 1 到第 8 个标签 |
| `Ctrl / Cmd + 9` | 跳转到最后一个标签 |
| `Ctrl / Cmd + Shift + D` | 复制当前会话 |
| `Ctrl / Cmd + Shift + M` | 复用当前 SSH 连接 |
| `Ctrl / Cmd + Alt + D` | 复制当前会话并指定启动命令 |
| `Ctrl / Cmd + Alt + M` | 复用 SSH 连接并指定启动命令 |

## 视图与布局

| 快捷键 | 功能 |
|--------|------|
| `Ctrl / Cmd + Shift + E` | 切换左侧边栏 |
| `Ctrl / Cmd + Shift + B` | 切换右侧边栏 |
| `Ctrl / Cmd + =` | 放大 |
| `Ctrl / Cmd + -` | 缩小 |
| `Ctrl / Cmd + 0` | 重置缩放 |
| `Ctrl / Cmd + ,` | 打开设置 |
| `Ctrl / Cmd + Alt + I` | 打开 AI 助手 |
| `Ctrl / Cmd + Shift + P` | 显示／隐藏底部快捷命令面板 |

`Ctrl / Cmd + Shift + P` 在设置里标为 **显示／隐藏快捷命令面板**。打开时聚焦搜索框，再次按下会隐藏面板并将焦点返回工作区；重新打开会保留筛选条件和面板高度。首屏的 **打开快捷命令** 入口只负责打开面板。

`Ctrl / Cmd + Shift + S` 打开命令面板浮层，用于搜索工作区标签、连接中的会话和已保存连接。

## 文件管理器

| 快捷键 | 功能 |
|--------|------|
| `F2` | 重命名选中的文件或目录 |

该快捷键只在文件浏览器获得焦点时生效。

## 已保存连接

| 快捷键 | 功能 |
|--------|------|
| `Ctrl / Cmd + Alt + C` | 复制选中的已保存连接 |

## 特殊功能

| 快捷键 | 功能 |
|--------|------|
| `Ctrl / Cmd + Shift + L` | 锁定屏幕 |

## 自定义快捷键

**设置 → 快捷键** 列出全部 32 条快捷键，按上面的六个分类分组，都可以改：

- 点击某条快捷键进入录制状态，直接按下新组合即可，回车或 **保存** 生效
- 新组合已被占用时会提示冲突对象，不会覆盖
- 改过的条目标为 **自定义**，可单条 **恢复默认**，也可 **全部重置**
- 搜索框按名称过滤

**切换到标签 1-9** 是一条模板快捷键，录制时需要按下修饰键加数字 `1`，运行时自动展开到 `1` 到 `9`。

## 使用建议

- 经常在终端里复制日志：记住 `Ctrl / Cmd + Shift + C`
- 同时管理远程与本地会话：`Ctrl / Cmd + Shift + N` 和 ``Ctrl / Cmd + ` ``
- 使用锁屏功能：记住 `Ctrl / Cmd + Shift + L`
