# 工作区与布局

NyaTerm 的核心体验不是“单个终端标签页”，而是一个可组合的工作区：你可以同时打开多个会话、拆分多个窗格，并把常用面板固定在左右两侧。

## 工作区的组成

典型工作区由几部分组成：

- **中央区域**：标签页与终端窗格
- **左侧活动栏 / 面板**：文件浏览器、网络、Security/Auth、云同步、设置
- **右侧活动栏 / 面板**：已保存连接、AI Assistant、活动会话、命令历史、资源监控
- **底部辅助区域**：快捷命令、串口发送、录制、锁定

这些区域不是固定死的单一页面，而是围绕当前活跃会话动态协作。

## 标签页

每个标签页承载一个会话。工作区可以分为多个标签组，每个区域都有独立的标签栏。

你可以对标签页执行这些常见操作：

- 新建会话
- 关闭当前标签
- 在标签之间切换
- 自定义标签名
- 给标签设置颜色
- 复制当前会话，或复制后执行启动命令
- 通过拖拽把标签停靠到其他分屏区域
- 重新连接会话
- 查看会话信息

标签名和颜色可以用来区分环境、项目或任务阶段。

## 命令面板

**命令面板** 是一个可搜索的浮层，用 `Ctrl / Cmd + Shift + S` 打开（设置中标为 **打开命令面板**）。它检索三类条目：

- **活动会话** — 当前已打开的标签
- **正在建立的会话** — 已发起但还没连上的会话，包含失败原因
- **已保存连接** — 连接列表里的条目，选中即发起连接

用键盘上下选择、回车打开。当打开的标签和连接很多时，这是最快的导航方式。

命令面板只检索会话和连接，**不包含**打开设置、切换面板、锁屏这类应用级动作——那些走顶部菜单或快捷键。

## 分屏能力

在标签页上右键，可以把当前会话拆成：

- **上下分屏**：复制当前会话，在当前区域下方打开新标签组
- **左右分屏**：复制当前会话，在当前区域右方打开新标签组

连接成功后，新会话进入新区域；连接失败会在原区域保留失败标签，其他区域仍可使用。拖动标签到目标区域中央会合并到该组，拖到四边会创建分屏，在标签栏内拖动可以调整顺序。移走最后一个标签会自动折叠空区域。典型用法：

- 一个窗格看日志，一个窗格执行命令
- 并排比较两台主机状态
- 左边本地终端，右边远程 SSH
- 串口输出和 SSH 排障命令同时观察

## 会话与工作区的关系

每个区域显示本组当前选中的会话，点击终端或标签会切换当前输入目标。`Ctrl+Tab`、`Ctrl+Shift+Tab` 和数字标签快捷键只切换当前组的标签；前后区域切换命令可以在设置中自行绑定快捷键。

顶部 **智能分屏** 只排列已经打开的会话。自动模式按中央区域的实际尺寸选择方向；空间不足时，一个区域会保留多个标签。**取消分屏** 会将全部区域的标签按区域与组内顺序合并，保留连接和当前活动会话。

拖动分隔条可以调整尺寸，双击恢复等分。缩小窗口会保留布局。聚焦模式临时只显示当前会话，退出后恢复原布局。

## 布局恢复与工作区间距

NyaTerm 会保存标签组布局，重启或重新打开工作区时恢复标签、分屏和活动位置。旧版本标签内部的分屏会转换为独立标签组，并保留方向、比例、标签名称、颜色和锁定属性。

**工作区间距** 用来在终端之间留出视觉边界。它只影响工作区的视觉间距，不改变远端或本地 shell 的行为。

## 左右侧面板

### 左侧

左侧更偏“能力入口”，通常包括：

- 文件浏览器
- 网络
- Security/Auth
- 云同步
- 设置

其中 **文件浏览器** 不只是静态目录树：在 SSH 会话中，它可以和当前终端 cwd 联动，并支持把当前目录或条目路径直接发回终端继续补命令。

其中 **云同步** 面板更偏“跨设备配置同步”的运行态入口：它会展示当前状态、最近的同步活动，并在发生冲突时提供直接处理入口。

查看最近一次同步结果时，工作区面板比设置页更直接。

### 右侧

右侧更偏“运行态信息”，通常包括：

- 已保存连接
- AI Assistant
- 活动会话
- 命令历史
- 资源监控
- NVIDIA GPU 监控
- Ascend NPU 监控
- 进程管理
- Docker 管理

这五个监控面板只对 SSH 会话有意义，各自由 **设置 → 终端** 中的开关控制是否显示；关闭开关会同时隐藏对应的活动栏图标。资源监控、进程管理和 Docker 管理默认开启，两个加速卡监控面板默认关闭。详见 [远程主机监控](./remote-monitoring)。


## AI Assistant 面板

**AI Assistant** 是右侧的常驻面板，不是独立弹窗，因此始终以当前活跃窗格为上下文：

- 根据自然语言生成一条终端命令
- 解释最近终端输出或当前选中的文本
- 分析错误并给出修复建议
- 生成可审批的命令卡片并执行
- 把命令保存为快捷命令

## 底部辅助区域

工作区底部承载不需要一直占用侧栏的能力：

- **快捷命令**：保存可复用命令片段，支持变量输入
- **串口发送**：向串口设备重复发送固定文本
- **录制**：开始或停止当前会话录制
- **锁定**：锁屏

## 子窗口

这些操作打开独立子窗口，不打断主工作区当前会话：

- 设置
- 新建连接
- 快捷命令编辑
- 远程文件编辑
- 自动上传提示

子窗口都在主窗口所在的显示器上、相对主窗口居中打开，有各自的任务栏项，可以最小化、最大化和还原。再次触发同一个操作不会开出第二个窗口，而是把已经打开的那个提到前面。

**新建连接**和**快捷命令编辑**各自独占一份草稿，所以它们是操作系统层面的模态窗口：打开期间主窗口由系统阻断，不接受任何输入，关闭后自动恢复并把焦点交还。**设置**在 Windows 和 Linux 上同样是模态窗口；macOS 上是独立窗口，因为那个平台的模态子窗口会变成贴在标题栏下的 sheet，而 Settings 按 Apple 的约定应该是独立窗口。

**远程文件编辑**是独立文档窗口，不阻塞主窗口——编辑远程文件时你往往需要回终端看输出、复制内容，锁住工作区反而碍事。**自动上传提示**同样不阻塞，但会保持置顶：它是在你用外部编辑器改完文件之后弹出的，看不见就等于没有提示。

`Ctrl / Cmd + W` 关闭当前子窗口；新建连接、快捷命令编辑和自动上传提示也响应 `Esc`。设置窗口不响应 `Esc`，并且在有未保存改动时关闭会先确认。

子窗口的位置和大小目前不会持久化，每次打开都重新居中。

## 托盘与窗口状态

在 **设置 → 常规** 中开启 **关闭最后一个窗口时最小化到托盘** 后，点击最后一个工作区窗口的 × 会保留工作区并转为后台驻留。多个工作区窗口同时存在时，点击 × 会经过正常确认、保存和清理流程，真正关闭当前工作区并从恢复清单移除；下次冷启动仅恢复保留的工作区。隐藏到托盘的工作区仍计入窗口数量。

再次启动程序、点击托盘图标或选择「显示最近使用的窗口」会唤醒已有窗口；菜单、托盘的「新建窗口」或 `--new-window` 才会新建独立工作区。「退出 NyaTerm」会保存并退出整个应用。最后一个窗口隐藏到托盘时，活动会话、同步和备份任务继续运行；托盘不可用时回退为普通最小化。

「启动时恢复先前的会话标签」仅控制会话标签，独立工作区窗口仍按保存清单恢复。已有的多余工作区不会自动删除，可逐个关闭不再需要的窗口。

## 同步输入组

同步输入组把多个终端会话绑在一起，你在其中一个会话里的按键会镜像到组内其他未暂停的会话。命令预览和历史记录只在你实际输入的那个会话上生成。

同步组是运行时状态，不会持久化，应用重启后需要重新建立。

### 创建与管理

1. 用 `Ctrl / Cmd + Shift + G` 或右侧活动栏打开 **同步输入组** 面板
2. 点击 **新建组**，设置名称和颜色
3. 从活跃会话列表中选择要加入的会话

活跃会话较多时可以按 **全部**、**可用**（未加入当前组）、**已加入** 或 **同主机** 筛选，搜索框支持按名称、类型、主机或会话 ID 过滤。

### 广播控制

- 整个组可以启用或暂停广播
- 组内单个会话可以单独暂停
- 已关闭的会话标记为 Missing，可一键清理

### 发送命令面板

底部 **发送命令** 面板提供目标选择：当前会话、全部会话，或某个具体的 `分组: <名称>`。选择分组目标时会自动按会话类型（串口与 shell）过滤，并排除已暂停或重复的会话。

快捷命令面板也提供 **发送到所有会话**，把命令一次性发送到所有活跃会话。
