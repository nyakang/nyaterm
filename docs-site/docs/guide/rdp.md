# RDP 远程桌面

RDP 会话连接 Windows 主机或其他提供 RDP 服务的远程桌面。它和终端会话共享标签页、分屏和已保存连接体系，但承载的是图形画面而不是文本终端。

RDP 的协议解码运行在独立的 helper 进程中。从源码运行时需要先构建 helper，否则连接会以 `HelperMissing` 失败，见 [开发环境搭建](../development/setup#rdp--vnc-需要先构建-helper)。

## 连接配置

### 基本信息

| 字段 | 说明 |
|------|------|
| 主机 / 端口 | RDP 服务地址，默认端口 `3389` |
| 用户名 | 登录用户名 |
| 域 | Active Directory 域，独立主机留空 |
| 密码 | 登录密码 |

### 安全

**网络级身份验证**（NLA / CredSSP）在远程主机支持时启用。

**证书策略** 决定首次遇到未知证书时的行为：

| 策略 | 行为 |
|------|------|
| 未知证书时询问 | 弹出验证对话框由你决定（默认） |
| 拒绝不受信任证书 | 直接拒绝，不询问 |
| 仅本次接受 | 接受但不写入信任记录，下次仍会询问 |

选择 **未知证书时询问** 时，对话框可以只接受本次连接，也可以接受并记住该证书。已保存的证书后续发生变化时，连接前会再次提示。

### 显示

**显示模式** 可选 **适应窗口**（默认）或 **固定尺寸**。选择固定尺寸时需要填写宽高：

- 宽度范围 **640 到 7680**
- 高度范围 **480 到 4320**

默认分辨率为 1920×1080，色深 32 位。

### 剪贴板

剪贴板始终开启，无需配置。内置后端支持双向文本和文件／目录复制，尚不支持图片和富文本通道。Windows Native 使用微软控件的完整剪贴板重定向，实际格式和文件传输能力取决于系统控件及服务端策略。

旧连接、备份或恢复会话中保存的关闭／仅文本值仍可读取，但不再限制运行时的剪贴板能力。剪贴板重定向不会同时开启磁盘、打印机或设备重定向。

### 重连

**自动重连** 默认开启，对临时网络故障做有限次数重试。**重试次数** 范围 **0 到 20**，默认 5 次。

## 能力边界

RDP 会话不提供这些 SSH 专属能力：

- 终端命令历史与命令建议
- SFTP 文件浏览器
- SSH 代理、跳板机与隧道
- 远程主机监控面板

需要命令行能力时使用 SSH、本地终端、Telnet 或串口会话。

## 错误分类

连接失败时的错误类型有助于判断方向：

| 类型 | 常见原因 |
|------|----------|
| `Authentication` | 用户名、密码或域不正确；NLA 要求未满足 |
| `CertificateRejected` | 证书策略拒绝了服务器证书 |
| `ConnectionRefused` / `Timeout` | 端口不可达、防火墙拦截或主机未启用 RDP |
| `Tls` / `Negotiation` | TLS 握手或协议协商失败 |
| `HelperMissing` | helper 可执行文件不在应用旁边 |
| `HelperCrashed` | helper 进程在会话期间退出 |
