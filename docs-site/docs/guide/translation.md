# 翻译功能

NyaTerm 内置多引擎文本翻译，用于在终端里翻译日志、报错或命令说明。

## 使用方式

1. 在终端中选中要翻译的文本
2. 右键打开上下文菜单
3. 在 **翻译** 子菜单中选择一个可用 provider
4. 翻译结果会在弹出对话框中显示

对话框中会展示：

- 原文
- 翻译结果
- 检测到的源语言（如果 provider 返回）
- 一键复制翻译结果

## Provider 显示规则

### 开箱即用

以下 provider 无需额外配置：

- **Google**
- **Microsoft**

### 需要凭据后才显示

以下 provider 只有在 **设置 → 翻译** 中填写了凭据后，才会出现在右键菜单里：

- **DeepL**
- **百度翻译**
- **阿里翻译**
- **有道翻译**

## 翻译设置

在 **设置 → 翻译** 中，你可以配置：

- **目标语言**
- 各 provider 对应的 **API 凭据**

## 典型用途

- 理解英文报错或第三方日志
- 查阅混合语言输出中的重点信息
- 翻译运维脚本说明或配置注释
