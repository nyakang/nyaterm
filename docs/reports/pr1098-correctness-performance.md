## 确认的问题及修复

### 1. 解析正确性

`semantic_roles.rs` 对权限行统一使用去除前导空白后的正文解析，再还原原始字节偏移。覆盖空格、制表符、Unicode 空白、SELinux `.`、ACL `+`、macOS `@` 及中文/组合字符文件名。

UTF-8 变异测试另外复现了 Gin 日志扫描推进到多字节字符内部的 panic。已修复该推进逻辑、时间戳截取和源代码位置后的空白偏移。角色解析统一验证所有返回范围，异常范围整体退回通用规则。

专用识别限制为不超过 8 KiB 的逻辑行。超过现有软换行组上限后降级的片段也禁止重新猜测角色，继续使用通用和用户规则。`ps` 先按第二字段的数字形状筛选，SQL 和编译器诊断不再构造中间大写字符串或前缀字符串。

### 2. 缓存一致性

新增 `TerminalKeywordHighlightConfig { line_roles, ansi }`，编译、结果身份、已编译缓存查找和发布校验使用同一配置。设置或规则变更推进代次和取消标识、清除不兼容结果，并重算当前视口。旧任务完成时必须同时通过代次、取消标识、配置和规则检查。

复用键包含输入/提示符元数据、软换行、备用屏幕及实际需要光标回退的上下文。普通输出行不因无关光标移动失效。保留旧前缀颜色时也检查上下文，避免跨输入状态保留无效颜色。

明确 Shell Integration 输出标记及备用屏幕优先于提示符形状；未集成的终端保留形状回退。新增冷算与复用结果逐行比较，覆盖连续中文输入、组合字符、退格、提交、补全、缩放和屏幕切换。

### 3. 后台调度与 UI 成本

移除 `apply_frame_snapshot()` 的同步补算及 `ensure_visible_keyword_highlights()`。规则编译、语义解析、结果数组和索引构造均在 `background_spawn` 内完成。帧应用和绘制不编译规则、不运行解析器。

每个 Surface 仅保留一个正在执行的解析任务。普通输出只更新最新待处理身份，任务完成后读取 Surface 最新快照，最多追加一次最新请求；配置变化才合作取消。取消后保留任务所有权直到返回，避免旧后台任务尚未退出就启动第二个。

先计算可见行，空闲时再预取；保留 50 ms 输出压力节流。可见区域匹配和绘制只生成相关行组的复用键，不再分配整份快照的键数组。

仅改变主题、没有新输出时也触发重算。内置提示符、命令、操作符及子字段缺省颜色直接来自 ANSI 调色板，启用规则的子字段优先使用该规则已解析的颜色。用户自定义颜色保留。

### 4. 设置持久化

新增兼容测试复现了原 PR 的真实保存错误：`ui.highlight_line_roles` 写入位于文件收藏夹保存函数，而开关通过外观设置保存，因此外观保存没有持久化这个值。

已将写入移至 `save_appearance_settings()`，保留原键名、字段名和缺省 `true`。测试验证旧文件加载、保存关闭、重新打开数据库、再启用及未知字段保留。另验证文件收藏夹保存不改变开关；遇到未来版本的非布尔表示时，未更改的安全缺省值不会覆盖原始数据，明确关闭则可保存为受支持的布尔值。

## 测量方法和适用边界

微基准运行真实公共预计算 API，构造快照和输出 CSV 不计入样本。覆盖普通文本、日志、结构化输出、ls、ps、约 2 KiB/8 KiB/超长逻辑行和 40/200/2000 行视口，分别测量角色开启/关闭的冷算、结果复用和可见区域匹配。历史祖先不含角色识别，其开/关标签是相同参考实现，不能解释为祖先提供该功能。

每轮交替原始/优化版本顺序及开/关顺序，至少 15 轮。所有版本使用同一工具链和 release profile；每次版本切换清理本仓库包产物，保留第三方依赖缓存，立即复制独立可执行文件并记录 SHA-256，防止相同包版本在多工作区之间混用产物。

原生窗口探针使用 Windows GPUI、真实 `TerminalSurface`、真实后台任务和呈现事件。固定节奏注入合成终端快照，覆盖输出期间输入及滚动。记录处理耗时、绘制耗时、呈现提交耗时、合成帧应用至呈现提交的延迟、补色轮询和最终追赶；外部进程采样 CPU 时间和进程峰值工作集。

原生探针不包含真实 PTY、操作系统键盘队列、网络和显示器扫描输出。呈现提交不等于屏幕实际显示，16 ms 轮询的补色延迟也不等于精确后台完成时间。该项仅统计轮询时已覆盖最新整屏的样本，合并掉的中间帧不计入，必须同时查看样本数及最终追赶时间。固定节奏行速率用于发现掉速，不能当作终端最大吞吐。所有截图和基准数据仅使用合成输出。
