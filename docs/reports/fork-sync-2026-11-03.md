## 补丁审计与主项目适配

- russh：融合上游认证前 keepalive 定时器重置；保留 Strict/Compatible、严格超时计数、无需回复的探测不占响应队列；测试 handler 适配 VerifiedPublicKey。
- VNC：保留上游先发布服务器布局再交付像素的顺序；客户端 resize 确认仍整包原子提交。资源上限、RA2 信任、安全类型选择未放宽。
- Alacritty：scroll epoch 与 screen/reset generation 两项补丁原样重放；未引入应用层。
- SSPI：0.23.1、picky rc.27；保留 ASN.1 最低版本 0.5.7/0.15.5 对旧 consumer lock 的兼容约束，独立 aes-gcm 0.11 消费验证通过。
- IronRDP：保留有序全帧请求、认证 loopback relay、原 TLS/CredSSP 身份、证书回调权威性与 relay 重定向拒绝。旧 SSPI 版本升级补丁由上游 0.23.1/rc.27 替代，独立保留 fork 来源覆盖；智能卡路径继续排除。独立审查未发现生产策略差异的新缺陷。
- Zed：保留动态纹理、原生拖放/file promise、取消手势、模态窗口、IME、Native RDP 浮层与游标补丁；融合 upstream objc2 Metal 迁移及 entity access tracking。旧 Metal 原始分配 workaround 被上游 typed/fallible allocation 完整替代，DirectX 检查保留。旧纯导入格式补丁由本轮 rustfmt 替代。
- DirectX：构造目标为 lower 时 above_children 同步初始化为 false；回归测试走真实构造路径并验证双目标切换。失败回滚和设备恢复保留。macOS 游标状态锁在 AppKit 调用前释放。
- Kit：升至 0.9.0，菜单外观/行高、标签布局、scrollbar hover、宏路径、原生浮层完整保留。融合 checkable 菜单状态、安全边距与关闭动画。关闭动画保留视觉但释放模态输入；既有点击穿透测试先失败、修复后通过。新增逻辑生命周期句柄，让解锁流程在弹窗开始关闭时立即拒绝旧结果，同时保留退出画面。
- 主项目：适配 ScrollEvent、on_scroll、ScrollSource；动态快捷键改用 KeyBinding::load 并保留原存储格式；滚动视口测试标记放入受限 shell；插件取消测试显式等待调度器释放接收端；只读菜单测试按上游跳过禁用项的导航规则验证禁用 Cut 与可用 Copy；RDP Input 0.9、PDU 0.11、SVC 0.10、Clipboard 0.9、Connector 0.12。所有 IronRDP patch 固定同一 revision，直接 GPUI 与 Kit 六个 Zed 依赖固定同一 revision。
